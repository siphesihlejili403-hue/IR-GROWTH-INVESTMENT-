# IR Growth Investment

IR Growth Investment is a South African-focused digital investment platform designed to provide users with a simple, secure, and transparent online investment experience.

## Features

- User registration and login
- Secure user dashboard
- Investment information
- Account balance and portfolio tracking
- Deposit and withdrawal management
- Transaction history
- Customer support
- Profile and verification management

## Technology

- Next.js / React
- Node.js
- PostgreSQL
- Secure authentication
- Responsive web design

## Project Status

🚧 Currently under development.

## Important Notice

Investment products, returns, deposits, withdrawals, and related financial services will only be offered in accordance with applicable South African laws and regulatory requirements.
